# CC-33: Marca de visita e o delta "desde que você saiu"

**Modelo:** Sonnet. **Depende de:** CC-23 (usa `marcosDe`).

---

## O problema

O Felipe toca 4-5 projetos em paralelo. Ao voltar num deles, a pergunta é "o que
mudou desde que eu saí", e hoje o painel só mostra o estado atual, que não
distingue o que ele já viu do que é novo.

## A decisão de desenho que não pode ser trocada

A marca de visita é **por botão explícito** ("vi isso"), nunca automática ao
abrir a aba. Ele olha o painel o dia inteiro; carimbar a visita a cada abertura
zeraria o delta o tempo todo e destruiria o próprio sinal.

## O que fazer

### 1. `visitas` no config

`src/config.mjs` já tem 13 funções `setX`. Siga o padrão exato de `setServidor`:

```js
export function setVisita(projeto, em = Date.now()) { … }  // grava { [projeto]: ms }
```

### 2. Rota

Em `web.mjs`: `POST /api/visita` com `{ projeto }`, no padrão de `comCorpo`.

### 3. O delta no cartão do cockpit

Em `porProjeto()` (`src/cockpit.mjs`), acrescente ao objeto de cada projeto:

```js
desdeVisita: { em: <ms da última visita ou null>, marcos: <n>, resumo: '3 tarefas fechadas · 1 agente novo' }
```

O `resumo` sai de `marcosDe(projeto, { desde: visitaEm })` (CC-23), contando por
tipo. Sem visita registrada, `desdeVisita.em` é `null` e o cartão mostra o botão
"vi isso" sem delta, não invente uma data inicial.

### 4. Botão no cartão

`data-visita="<projeto>"`, no padrão dos outros botões do `ui.html`
(handler no listener de clique, perto de `data-rt-*`).

## Armadilhas que se aplicam

- **`porProjeto()` é chamado no caminho barato**, a cada 2s. `marcosDe` lê um
  JSON, aceitável. Se ficar lento com histórico grande, cacheie por
  tamanho+mtime do arquivo, como `transcript.mjs` faz. Meça antes de otimizar.
- **`CONFIG_FILE` não é isolado por porta**: testando em `--port 8123`, você
  escreve no config real do Felipe. Se gravar visita de teste, remova a chave
  depois, **nunca** restaure o arquivo inteiro de um backup.
- **Não colocar número na tela.** A regra do cockpit é frase, não peso. "3
  tarefas fechadas desde sua última visita", não "delta: 3".

## Como verificar

1. `npm test` com assert: projeto sem visita tem `desdeVisita.em === null`;
   com visita no passado, conta só os marcos posteriores.
2. Clicar "vi isso" e confirmar que o delta zera, e que **só** aquele projeto
   zerou.
