# CC-1064: rascunho, a conversa que ainda não é projeto

Pedido dele em 19/10: *"sabe o que eu sinto falta? De uma sessão de Claude que seja uma sessão soh de ideias,
genérica sabe? Sem projeto. (...) Precisamos de um chat temporário que pode virar projeto ou não."*

Desenho escolhido por ele (caixa de pergunta, 19/10): **pasta de rascunho**. Lugar na fila: agora.

## O nome na tela

**Rascunho.** "Ideias" já é outra coisa no painel (a fila de ideias de cada projeto, tela `#ideias`, `src/ideias.mjs`),
e regra de escrita 3 proíbe o mesmo nome para duas coisas. Na tela: "Rascunhos: conversas que ainda não são projeto".

## O que é cada peça

- **Pasta do rascunho:** `<base dos projetos>/_rascunhos/<slug>/`. O `_` na frente já tira a pasta de toda varredura
  de projeto (`SKIP` em `src/install.mjs:21` pula nome começado por `_`). Dentro: `IDEIA.md` e `.claude/CLAUDE.md`.
  **Nunca** `CLAUDE.md` nem `.git` na raiz da pasta: é esse o critério de "é projeto" (`isProject`, `install.mjs:216`).
- **Sessão do rascunho:** a mesma do resto do painel, `ligar(rotulo, pasta, { remoto: true })` de `src/remotecontrol.mjs`,
  com rótulo `rascunho-<slug>`. Com isso ela aparece no app do celular, e o cartão de sessão morta (feito hoje) já cobre
  o reinício da VPS.
- **`IDEIA.md`:** o estado da ideia, mantido pela própria sessão (instrução no `.claude/CLAUDE.md`). É ele que viaja
  quando o rascunho vira projeto, então não há passo de "resumir a conversa".
- **Virar projeto:** cria o projeto pelo MESMO caminho do botão de projeto novo (`criar` de `src/novoProjeto.mjs`),
  leva o `IDEIA.md` para `docs/produto/IDEIA.md`, copia o histórico da conversa e reabre a sessão já no projeto.
- **Descartar:** encerra a sessão e move a pasta para `_rascunhos/.lixeira/<slug>-<AAAAMMDD-HHMM>`. Não apaga: dá para
  recuperar à mão. Apagar de vez fica para quando a lixeira incomodar.

## Medido antes de planejar (19/10)

- `KillMode=process` no serviço `agent-cockpit`: reiniciar o painel mata só o processo principal; o tmux, que mora no
  grupo do painel, sobrevive. Reiniciar para publicar é seguro para as sessões vivas.
- `ligar()` grava o vínculo com `conversa: null` quando a conversa ainda não tem arquivo, e isso deixou três sessões sem
  volta no reinício de hoje. O `conversaDoVinculo()` novo (mesmo arquivo) resolve pela pasta; use-o.

## M1. Núcleo: `src/rascunhos.mjs` (arquivo novo)

Sem dependência nova. Toda escrita em `~/.claude` passa por `casaClaude()` (respeita `CC_HOME`).

```
export const ROTULO = (slug) => `rascunho-${slug}`
export function baseRascunhos()          // process.env.CC_RASCUNHOS || path.join(projectsBase() || path.join(os.homedir(), 'projetos'), '_rascunhos')
export function ehRascunho(dir)          // true se dir está dentro de baseRascunhos() (comparar com path.resolve + path.sep)
export function slugDe(titulo)           // minúsculo, sem acento (normalize NFD + tirar \p{M}), só [a-z0-9-], até 40, sem hífen nas pontas; vazio vira 'rascunho-AAAAMMDD-HHMM'
export function listar({ vivos = {} })   // puro em cima do disco: pastas de baseRascunhos() menos as que começam com '.'
                                         // cada uma: { slug, titulo, resumo, criadoEm, mexidoEm, rotulo, viva: Boolean(vivos[rotulo]), conversa }
                                         // titulo = 1ª linha '# ...' do IDEIA.md, senão o slug; resumo = 1º parágrafo depois do título, até 240 chars
                                         // mexidoEm = mtime do IDEIA.md; ordem: mexidoEm desc
export async function criar({ titulo }, { ligar = ligarRC } = {})
export async function descartar(slug, { desligar = desligarRC } = {})
export async function promover(slug, { nome }, { ligar = ligarRC, desligar = desligarRC, criarProjeto = criarNovo, base = projectsBase() } = {})
```

As dependências entram como parâmetro com padrão, para o teste não abrir tmux nem criar projeto de verdade.

**criar:** `slug = slugDe(titulo)`; se a pasta existe, `-2`, `-3`... Cria a pasta, `IDEIA.md` com o modelo abaixo, e
`.claude/CLAUDE.md` com o texto fixo abaixo. Depois `ligar(ROTULO(slug), pasta, { remoto: true })`. Se `ligar` falhar,
a pasta FICA (a conversa pode ser aberta de novo) e devolve `{ ok: false, erro, slug }`. Sucesso: `{ ok: true, slug, ...r }`.

`IDEIA.md` inicial:
```
# <titulo>

(ainda vazio: a conversa preenche)

## O que foi decidido

## O que falta decidir

## Perguntas em aberto
```

`.claude/CLAUDE.md` (texto exato):
```
# Rascunho, não projeto

Esta conversa é um rascunho de ideia. Ainda não é projeto, e talvez nunca vire.

- Converse, pesquise, compare. Não crie estrutura de projeto, não rode git init, não crie app.
- Mantenha o IDEIA.md desta pasta sempre atualizado: a ideia em um parágrafo logo abaixo do título,
  o que foi decidido, o que falta decidir e as perguntas em aberto. Atualize ao fim de cada resposta
  em que algo mudou. É ele que vira a semente do projeto se a ideia for adiante.
- Arquivo de apoio (rascunho de texto, tabela, esboço) pode ficar nesta pasta.
- Para virar projeto ou descartar, o Felipe usa os botões do painel (tela Sessões, bloco Rascunhos).
```

**descartar:** `desligar(ROTULO(slug))` (já anota o caminho de volta e marca `encerradaEm`), depois
`fs.renameSync(pasta, path.join(base, '.lixeira', `${slug}-${carimbo}`))` com `mkdir` da lixeira antes. Slug que não
existe: `{ ok: false, erro: 'não achei o rascunho <slug>' }`. Validar `slug` com `/^[a-z0-9][a-z0-9-]{0,60}$/` em TODA
função que recebe slug (é texto que vem da tela e vira caminho: barra ou `..` não podem passar).

**promover:** valida `nome` com `validarNome` de `novoProjeto.mjs`. Ordem, cada passo registrado em `passos`:
1. Lê o vínculo do rótulo (`lerVinculos()`) e resolve a conversa com `conversaDoVinculo` (exportar de
   `remotecontrol.mjs` se ainda não for exportada).
2. `desligar(ROTULO(slug))`.
3. `criarProjeto(base, { nome, descricao: titulo })`. Falhou: devolve o erro, o rascunho continua intacto.
4. Copia `IDEIA.md` para `<raiz>/docs/produto/IDEIA.md` (mkdir antes). Outros arquivos da pasta (menos `.claude/`) vão
   para `<raiz>/docs/produto/rascunho/`.
5. Se há conversa: COPIA (não move) o `.jsonl` de `~/.claude/projects/<pasta do rascunho codificada>/` para
   `~/.claude/projects/<raiz codificada>/`. A codificação é a do `pastaTranscritos` do `remotecontrol.mjs`
   (`String(cwd).replace(/[^a-zA-Z0-9]/g, '-')`): exporte uma função em vez de repetir a regra. Falha na cópia não
   para a promoção: vira passo com `ok: false`.
6. `ligar(nome, raiz, { remoto: true, retomar: conversa })` se a cópia deu certo; senão
   `ligar(nome, raiz, { remoto: true, pedido: 'Leia docs/produto/IDEIA.md: é a ideia que deu origem a este projeto.' })`.
   **Medido em 19/10:** `claude --resume` aceita a conversa copiada para a pasta do projeto novo. Prova: rascunho de
   teste com uma ideia de receitas virou o projeto `VPS_teste-ideia`, e a sessão reaberta mostrava o turno anterior
   (a edição do `IDEIA.md`) e continuou dele. O caminho do `pedido` fica só para quando a cópia falhar.
7. Move a pasta do rascunho para a lixeira (mesmo carimbo do descartar), nunca apaga.
Devolve `{ ok: true, raiz, nome, passos, sessao: r }`.

Prefixo do nome: a tela sugere `VPS_<slug>` ou `PC_<slug>` conforme a máquina. A regra mora no servidor:
`prefixo()` em `rascunhos.mjs` usando `ehWindows` (o mesmo que `remotecontrol.mjs` importa), `'PC_'` ou `'VPS_'`.
`process.platform` não pode aparecer fora de `platform.mjs`.

## M4. O painel enxerga: `src/cockpit2.mjs` e `src/ui_cockpit2.html`

**cockpit2.mjs:** sessão cujo `cwd` está num rascunho (`ehRascunho`) não pode virar projeto na tela Projetos. Leia
`montar()` (linha ~615) e ache onde a sessão vira projeto (`projetoDe(j.project)`); marque o projeto com
`rascunho: true` e a sessão com `rascunho: true`. A tela Projetos filtra `rascunho`. A sessão continua na tela Sessões
(pergunta e permissão dela precisam aparecer).

**ui_cockpit2.html:** na tela Sessões, um bloco "Rascunhos" no topo da lista, antes dos cartões:
- título: "Rascunhos" e, embaixo, em texto menor: "conversas que ainda não são projeto";
- botão "novo rascunho": `prompt('Sobre o que é a ideia?')`, POST criar, depois recarrega a lista; enquanto espera,
  o botão diz "abrindo, leva uns 15 segundos…";
- uma linha por rascunho: título, resumo em texto apagado, "há X" (`mexidoEm`), pílula "no ar" ou "parado";
  botões: "virar projeto" (`prompt('Nome da pasta do projeto', prefixo + slug)`, POST promover, mostra os `passos`
  num aviso), "descartar" (`confirm('Descartar "<título>"? A pasta vai para a lixeira dos rascunhos e dá para recuperar.')`).
  Rascunho parado ganha "reabrir", que usa a mesma ação `reabrir` de `/api/remote-control` com o rótulo `rascunho-<slug>`;
- sem nenhum rascunho: "Nenhum rascunho. Use para conversar sobre uma ideia sem criar projeto: se ela for adiante, vira
  projeto com um toque."
- Busca `/api/rascunhos` ao abrir a tela Sessões e depois de cada ação. Nunca no tique de 2s.
- O cartão de sessão de rascunho leva a pílula "rascunho" ao lado do nome.

Armadilhas desta página, todas já pagas (ver `CLAUDE.md` do projeto): campo de texto dentro de bloco redesenhado de 2 em
2 s perde o foco (por isso `prompt()`, não `<input>`); grade é classe, nunca `style="grid-template-columns"`; crase
dentro de comentário HTML dentro de template literal mata a página; o seletor que `render()` troca por `outerHTML`
precisa conter o bloco inteiro senão ele duplica; bloco novo usa `pintar(el, html)`. Nenhum travessão em texto de tela.
