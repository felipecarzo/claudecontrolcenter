SSE (Server-Sent Events)

ARQUITETURA ATUALIZADO HÁ 2 DIAS

Server-Sent Events (SSE) é a tecnologia que usamos no Control Center para transmitir o log do Claude e o estado da fila do Agent Cockpit em tempo real para o front-end ui.html e ui_v2.html, sem precisar de websockets ou long-polling.

Como funciona no Cockpit

  • O servidor Node (`web.mjs`) expõe a rota /events.
  • O browser conecta via new EventSource('/events').
  • O payload recebido AGENTS_UPDATED traz a fila perdida, os bloqueios, e os agentes waiting.
// Exemplo de payload
{
  "event": "AGENTS_UPDATED",
  "agents": [...],
  "filaPerdida": []
}
